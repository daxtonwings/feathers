

macOS系统推荐`brew install openssl@3`安装openssl

不过已经通过源码编译了openssl
```bash
which openssl
# /usr/local/bin/openssl

openssl -v
# OpenSSL 3.2.3 3 Sep 2024 (Library: OpenSSL 3.2.3 3 Sep 2024)
ll /usr/local/include/openssl  # 头文件

ll /usr/local/lib/libssl.*
# lrwxr-xr-x  1 root    wheel    72B  6 26  2021 /usr/local/lib/libssl.1.0.0.dylib -> /Applications/EasyConnect.app/Contents/Resources/Libs/libssl.1.0.0.dylib
# lrwxr-xr-x  1 abakus  admin    50B  1 12  2024 /usr/local/lib/libssl.1.1.dylib -> /opt/homebrew/opt/openssl@1.1/lib/libssl.1.1.dylib
# -rwxr-xr-x  1 root    admin   851K 12 16  2024 /usr/local/lib/libssl.3.dylib
# -rw-r--r--  1 abakus  admin   445K  5 10  2024 /usr/local/lib/libssl.55.dylib
# -rw-r--r--  1 root    admin   1.4M 12 16  2024 /usr/local/lib/libssl.a
# lrwxr-xr-x  1 root    admin    14B 12 16  2024 /usr/local/lib/libssl.dylib -> libssl.3.dylib
# -rw-r--r--  1 abakus  admin   935B  5 10  2024 /usr/local/lib/libssl.la
```

那么在cmake构建时推荐
```bash
cmake .. \
  -DCMAKE_PREFIX_PATH="/usr/local" \
  -DOPENSSL_ROOT_DIR="/usr/local" \
  -DOPENSSL_INCLUDE_DIR="/usr/local/include" \
  -DOPENSSL_LIBRARIES="/usr/local/lib"
```
